# Voice Commander - Assistent de Veu d'Escriptori

**Voice Commander** és una aplicació d'escriptori desenvolupada amb **Electron** i **Vue.js** que permet als usuaris interactuar amb l'ordinador mitjançant comandes de veu. Aquest projecte demostra la integració de tecnologies web modernes en un entorn d'escriptori natiu.

## 🚀 Tecnologies Utilitzades

Aquest projecte s'ha construït utilitzant la següent pila tecnològica:

* **Electron:** Per a l'encapsulació d'escriptori.
* **Vue.js (Vue 3):** Framework JavaScript per a la interfície d'usuari.
* **Vuetify:** Llibreria de components de disseny Material Design.
* **Vite:** Empaquetador i servidor de desenvolupament ultraràpid.
* **Node.js:** Entorn d'execució.

## 📋 Requisits Previs

Abans de començar, assegura't de tenir instal·lat:
* [Node.js](https://nodejs.org/) (Versió 16 o superior)
* npm (normalment ve amb Node.js)

## 🛠️ Instal·lació i Execució

Segueix aquests passos per posar en marxa el projecte en el teu ordinador local:

1.  **Clonar el repositori:**
    ```bash
    git clone [https://github.com/tu-usuari/ExerciciVeuAymar.git](https://github.com/tu-usuari/ExerciciVeuAymar.git)
    cd ExerciciVeuAymar/vuetify-project
    ```

2.  **Instal·lar les dependències:**
    És crucial instal·lar les llibreries necessàries abans d'executar res.
    ```bash
    npm install
    ```

3.  **Executar en mode desenvolupament:**
    Aquest comando obrirà l'aplicació en una finestra d'escriptori.
    ```bash
    npm run electron:dev
    ```

## 📖 Ús Bàsic

1.  Obre l'aplicació.
2.  Navega a la pestanya o secció "Voice Commander".
3.  Prem el botó del micròfon per activar l'escolta.
4.  Pronuncia la teva comanda. L'aplicació mostrarà el text reconegut en pantalla.
